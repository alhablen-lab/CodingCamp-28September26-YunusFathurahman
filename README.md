## Expense & Budget Visualizer

A simple web application to record and visualize daily expenses.

## Features

* Add transactions
* Input validation
* Delete transactions
* Calculate total spending automatically
* Spending chart by category
* Save transactions using Local Storage
* Sort transactions by amount and category
* Spending limit warning
* Dark and Light Mode
* Responsive design

## Categories

* Food
* Transport
* Fun

## Technologies

* HTML5
* CSS3
* JavaScript
* Chart.js
* Local Storage

## How to Run

1. Open `index.html` in a modern web browser.
2. Add your transactions.
3. Use the available features to manage and visualize your spending.
